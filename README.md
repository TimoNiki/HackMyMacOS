# HackMyMacOS
Программа создана для того чтобы просмотреть/изменить настройки macOS которые тяжело найти в настройках.
и чтобы долго не искать появилась программа от меня которая называется HackMyMacOS.

# как установить чтобы работало?
если вы используете исполняемый файл который лежит в архиве то его просто так не открыть
так как программа не является оригинальной проверенной Apple. 
Вот как сделать чтобы запустить программу из архива:

1. распакуйте архив в папке с архивом появится исполняемый файл
2. нажмите правой кнопкой мыши по исполняемому файлу и выберите открыть
